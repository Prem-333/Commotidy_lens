# CommodityLens light palette

The default interface uses warm ivory, white surfaces, navy typography, and restrained gold accents. Dark mode remains available in Settings. Existing preferences migrate to light once; subsequent choices persist.

| Role | Color | Use |
| --- | --- | --- |
| Warm ivory | `#F8F7F3` | Page background |
| White | `#FFFFFF` | Cards, tables, chart surfaces |
| Deep navy | `#172B4D` | Primary text and action buttons |
| Antique gold | `#806014` | Active navigation, accents, primary chart series |
| Champagne | `#F5EEDC` | Selected items and gold badge backgrounds |
| Slate | `#526176` | Secondary text |
| Mist | `#DCE2E8` | Dividers and card borders |
| Emerald | `#176D50` | Positive states |
| Rose | `#AC324B` | Negative states and warnings |
| Steel blue | `#285D97` | Information and comparison series |
| Violet | `#7650A8` | Additional comparison series |

Use white text on navy buttons; use navy or slate text on light surfaces. Gold is an accent, not a large-area background. Chart heatmaps use pale emerald, neutral gray, and pale rose with navy labels. Keep text labels and symbols alongside status colors.
